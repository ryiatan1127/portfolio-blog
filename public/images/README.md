# 素材图片

放网站装饰素材图片，访问路径即 `/images/...`。

## 当前约定

- **`lace-nav.png`** —— 菜单栏的淡淡蕾丝背景。
  - 横向蕾丝花边（透明背景 PNG），宽度 ≥ 1920px、高度约 80~120px 最佳。
  - 放入后立即生效（横向平铺、高度自适应菜单栏）；删除后菜单栏自动恢复无背景。
- **`*.png` 贴纸图** —— Hero 漂浮物素材（`components/ParticleBackground.tsx` 的 `SPRITE_SPECS` 引用）。
  - 用**透明底 PNG**（直接正常混合绘制，透明处不遮挡背景）。
  - 漂浮物与粒子同一套逻辑：按可视面积随机生成数量、全屏随机分布、慢速漂移、边界环绕、随窗口 resize 重铺。
  - 想调整尺寸/密度/各类数量：改 `SPRITE_SPECS`（`minH/maxH` 高度范围、`w` 选取权重）与 `spawnSprites()` 的密度常数。
  - 想新增漂浮物：把透明底 png 放进本目录，加一条 `SPRITE_SPECS` 配置即可。
