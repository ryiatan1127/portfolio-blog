# 自定义字体目录

把字体文件放到本目录，即可在对应位置使用（无需改代码）。`@font-face` 已同时声明三种格式，浏览器按 woff2 → ttf → otf 顺序加载存在的文件。

| 用途 | 字体名 | 文件名（任选其一） |
|---|---|---|
| 标题 / Logo（英文 / 拉丁字符） | Display-En | `display-en.woff2` / `display-en.ttf` / `display-en.otf` |
| 标题 / Logo（中文字符） | Display-Zh | `display-zh.woff2` / `display-zh.ttf` / `display-zh.otf` |
| 主页中央大字「Ryia」 | Hero | `hero.woff2` / `hero.ttf` / `hero.otf` |
| 正文（英文 / 拉丁字符） | Body-En | `body-en.woff2` / `body-en.ttf` / `body-en.otf` |
| 正文（中文字符） | Body-Zh | `body-zh.woff2` / `body-zh.ttf` / `body-zh.otf` |
